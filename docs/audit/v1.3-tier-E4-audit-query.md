# v1.3 Tier E4 — Admin Paginated Audit-Log Query Endpoint

**Branch:** `feat/e4-audit-query-endpoint`
**Roadmap reference:** Tier E, row E4 (admin paginated audit-log query endpoint, filter by action/user/date; the audit table is write-only from the API today).

## Design (decided)

### 1. New `audit` module (canonical shape)

`internal/module/audit/` with `dto` / `usecase` / `handler` / `port` + `module.go`, following the user-module pattern:
- `GET /audit/logs` — `Auth` + `RequirePermission(authorizer, "audit", "read")`.
- Query params: `action`, `user_id`, `resource`, `start_time` / `end_time` (RFC3339), `limit` (default 50, capped 100), `cursor`.
- Response: `shareddomain.CursorPage[AuditLogResponse]` (same envelope as user List).
- Invalid `cursor` / time format → 400. Auditor errors → 500 via `apperr`.

### 2. Keyset cursor in the adapter

- `port` gains the cursor codec (`EncodeAuditCursor(time, id)` / `DecodeAuditCursor`) — `port` is already imported by both the adapter and the module, so the format lives in exactly one place.
- `PostgresAuditor.Query` honors `filter.Cursor`: `AND (created_at, id) < ($t, $id)`, deterministic `ORDER BY created_at DESC, id DESC` (id tiebreak added). Invalid cursor → error. No production callers of `Query` exist today, so the behavior change is contained.
- Module fetches `limit+1`, trims, mints `next_cursor` from the last entry when there is an extra row.

### 3. Permission seed (migration 000005)

- `000005_audit_read_policy.up.sql`: `('p','admin','audit','read')` (+ superadmin already wildcarded) with `ON CONFLICT DO NOTHING`, mirroring 000003's style. Down deletes the row.
- The F1 round-trip test's expected version moves 4 → 5; the testutil fixture copy gains the new files (drift gate enforces).
- No DDL: table shape untouched.

### 4. Spec + wiring

- `docs/openapi.yaml` (or `internal/module/docs/openapi.yaml` — whichever the drift tool reads): `GET /audit/logs` with params + 200/400/401/403. The B1 drift gate must stay green.
- `app.go` + `testutil/testapp.go` wiring (auditor + authorizer + both JWT secrets, like the job module).

## Out of scope

- Backward (`prev`) pagination (user module has it; audit starts forward-only).
- `total` counts (no `COUNT(*)` — unbounded table).
- Export (CSV) or text search on metadata.
